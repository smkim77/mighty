# ♠ 마이티 (Mighty) - Godot 4 웹/데스크톱 1인용 게임

한국형 5인용 트릭테이킹 카드 게임 **마이티(Mighty)**의 1인용(플레이어 1명 + AI 4명) Godot 4 프로젝트입니다.

## 주요 구현 기능
- **5인 53장 표준 룰**: 1인당 10장 배분 + 바닥패(키티) 3장
- **경매(공약) 시스템**: 기루다 문양(`♠`, `♦`, `♥`, `♣`, `노기루`) 및 목표 점수(13~20점) 입찰, 딜미스 선언 지원
- **바닥패 교환 & 프렌드 지정**:
  - 주공 당선 시 바닥패 3장 획득 후 3장 버리기
  - 마이티 프렌드, 조커 프렌드, 기루다 A/K 프렌드, 초구 프렌드, 노프렌드 지원
- **특수 카드 규칙 완벽 반영**:
  - **마이티 (`♠A`, 스페이드 기루다 시 `♦A`)**: 최강 카드, 기루다 변경 시 자동 반영
  - **조커 (`🃏`)**: 선공 시 요청 문양 지정, 초구(1라운드)/막구(10라운드) 무력화
  - **조커 콜 (`♣3`, 클로버 기루다 시 `♠3`)**: 선공 시 조커 강제 호출
- **점수 정산**: 여당(주공+프렌드) vs 야당(수비 3인) 획득 점수 계산, 런(Run)/백런(Back-run)/노프렌드/노기루 배수 반영

## 실행 및 웹(HTML5) 내보내기 방법
1. **Godot 4 에디터에서 실행**:
   - Godot Engine 실행 → `d:/_git/mighty/project.godot` 열기 → `F5` (실행)
2. **웹(Web) 빌드 내보내기**:
   - `export_presets.cfg`에 `Web` 프리셋(`docs/index.html`)이 설정되어 있습니다.
   - Godot 메뉴 **Project → Export... → Web → Export Project**로 바로 웹 빌드를 생성할 수 있습니다.
